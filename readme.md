преобразование речи в текст с возможностью разделения спикеров
клиент-серверная архитектура, клиент и сервер представлены в данном проекте

клиент позволяет:
* захват звука с микрофонов
* захват звука с динамиков
* получение звука из любого медиа файла

клиент передаёт данные на сервер и получает результат онлайн, задержка ответа примерно 25 секунд

клиент
python, flet. 
Может быть собран под windows и linux
Есть сборка дистрибутива для инсталляции для windows, использованы pyinstaller и Inno Setup
подключение к серверу порт 8732 по http, для получения результатов обработки от сервера используется web-socket
полченый в резудьтате обработки звука текст можно обработать с помощью LLM - сделан соответствующий довольно удобный интерфейс

сервер (main)
python, fastapi
клиент подключается к серверу, аутентификация пользователя через LDAP
обеспечивает получение заданий от клиентов, организацию их обработки воркерами, возврат результатов клиентам
хранение данных записанных сейсий
сохранеие образцов голосов (эмбедднгов) с присвоенными им именами

воркер - голос-в-речь без диаризации (stt)
pthon
использован faster-whisper

воркер - голос-в-речь с сегментацией по спикерам (sttd)
c++
использована модель mudler/moss-transcribe.cpp-gguf (см. также MOSS-Transcribe-Diarize)
возвращает сегменты распознаного текста разбитого по спикерам и временные рамки сегментов
эта модель работает существенно медленне чем faster-whisper, но выполняет сегментацию
в чистом виде для обработки длинных аудио требует много видео-памяти, но у нас обрабатываются короткие фрагменты аудио (до 20 сек) поэтому память нужно немного

воркер - формирование итоговых спикеров (spkemb)
python, torch, wespeaker
извлекает эмбединги из сегментов, группирует, сопоставляет с ранее записанными спикерами
для получения эмбеддингов использована модель wespeaker-voxceleb-redimnet2-B6-LM
используется после stt в начале сессии для определения говорщего
используется после sttd для формирования списка спикеров (объединения спикеров между сегментами)

обмен командами между сервером и воркерами организован через web-socket
обмен данными между сервером и воркерами организован через общую файловую систему

для запуска сервера: 
скачайте и распакуйте архив listelog_QuickStart.zip
запустите prepare.sh - скачает ИИ модели
запустите start_server.sh - первый запуск будет довольно долгим - будут скачиваться docker images
откройте в браузере http://localhost:8732/ и скачайте клиент

Сервер для загрузки медиа-файлов
сканирует каталог/каталоги (любые, в том числе сетевые)

настройка 
scan_dir - сканируемый каталог/каталоги (если он один)
scan_dirs_file - путь к файлу со списком каталогов
work_dir - каталог для хранения временнх файлов и прочего нужного

для docker/linux пердполагается использование scan_dir в который поткаталогами смонтировать нужные другие

пример .env
PORT=8732
TOKEN=<токен подключения к основному серверу>
SCAN_INTERVAL=0.1
HOST_SCAN_DIR="C:/tests/file_server/scan"
HOST_WORK_DIR="C:/tests/file_server/work"
